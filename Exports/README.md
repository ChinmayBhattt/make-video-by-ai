# Exports

Finished renders of edited videos, ready for review and posting.

## What goes here
- Final video files (MP4, MOV) exported from edits
- Different versions for different platforms (vertical, square, horizontal)

## Tips
- Name files to match the Raw folder, e.g. `2026-11-02_product-launch_v1.mp4`
- Use `_v2`, `_v3` for revisions
- Once you approve an edit, move it to `Approved Videos`
