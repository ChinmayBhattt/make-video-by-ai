# Raw

Unedited footage waiting to be edited. One folder per video.

## What goes here
Make one subfolder per video, named with a date and short title:

```
Raw/
  2026-11-02_product-launch/
    footage-01.mp4
    footage-02.mp4
    brief.md
```

Inside each video folder:
- Raw clips, b-roll, voiceover, audio
- `brief.md` (optional): goal, platform, target length, key points, anything to include or avoid

## Tips
- Keep everything for one video in its own folder
- Don't edit or rename originals once added
